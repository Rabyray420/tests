# Баг-репорты

Найденные дефекты магазина Aloha Threads (https://mysuperpetproject.ru/). Первая запись пока черновик: нужно подтвердить воспроизведение.

## BUG-01. После оформления заказа не приходит письмо с подтверждением (черновик)

| Поле | Значение |
|---|---|
| Заголовок | После оформления заказа не приходит письмо с подтверждением, хотя страница сообщает, что оно отправлено |
| Шаги | 1. Оформить заказ и нажать «Оплатить» (демо-режим оплаты). 2. Дождаться страницы подтверждения. 3. Проверить почту, указанную при оформлении (включая папку «Спам»). |
| Ожидаемый результат | На почту приходит письмо с информацией о заказе |
| Фактический результат | Письмо не пришло (требует повторной проверки) |
| Серьёзность | Предварительно высокая: покупатель не получает подтверждение |
| Окружение | Боевой сайт; браузер и устройство уточнить |
| Статус | Черновик, нужно подтвердить |

Что осталось уточнить: на какой адрес оформлялся заказ, проверена ли папка «Спам», через какое время смотрели почту, какие браузер и устройство.
