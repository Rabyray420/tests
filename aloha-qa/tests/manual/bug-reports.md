# Баг-репорты магазина Aloha Threads

Найденные дефекты mysuperpetproject.ru. Улучшения и доработки ведутся как GitHub Issues, кейсы — в `test-cases.md`.

## BUG-01 — не приходит письмо с подтверждением заказа
| Поле | Значение |
|---|---|
| Заголовок | После оформления заказа не приходит письмо с подтверждением, хотя страница сообщает, что оно отправлено |
| Шаги | 1. Оформить заказ и нажать «Оплатить» (демо-режим). 2. Дождаться страницы подтверждения. 3. Проверить почту, указанную при оформлении, включая папку «Спам». |
| Ожидаемый результат | На почту приходит письмо с информацией о заказе (номер, состав, сумма, адрес доставки) |
| Фактический результат | Письма нет ни во «Входящих», ни в «Спаме», хотя с момента заказа прошло много времени. Заказ оформлялся на личную почту. Письма с других сайтов на эту почту приходят, с магазина — нет (2026-10-01 со слов владельца, подтверждено 2026-10-16) |
| Серьёзность | Major: функция заявлена на странице подтверждения, но не работает; данные не теряются и заказ оформляется |
| Приоритет | высокий: владелец ожидает письмо, без него покупатель не получает подтверждения на почту |
| Окружение | боевой сайт mysuperpetproject.ru; Chrome 154.0.8037.59, Windows 10 (сборка 19045.6466) |
| Статус | подтверждён (2026-10-16) |
| Связанные кейсы | ORD-02 (пропущен до исправления) |

Возможная причина (гипотеза по коду, не вывод): в коде магазина нет вызова отправки почты (проверено по рабочей копии 2026-10-08), поэтому письма не уходят вообще. В баг-репорте описано только то, что видно пользователю.

## BUG-02 — при отмене заказа администратором остаток товара не возвращается
| Поле | Значение |
|---|---|
| Заголовок | При смене статуса заказа на «отменён» остаток товара не возвращается |
| Шаги | 1. Оформить заказ на 2 шт. TEST-SHIRT (остаток 3, после заказа 1). 2. Войти администратором, открыть «Заказы». 3. В выпадающем списке статуса заказа выбрать «отменён». 4. Открыть страницу товара TEST-SHIRT. |
| Ожидаемый результат | Остаток товара равен 3: товар вернулся в остаток (решение владельца 2026-10-08, в том числе для отправленного заказа) |
| Фактический результат | Остаток остался 1 (проверено 2026-10-16 для остатка товара; остаток по размерам отдельно не проверялся; у товара заданы размеры). Повторяется для заказа в статусе «отправлен» |
| Серьёзность | Major: склад занижается, товар «заканчивается» без реальных продаж |
| Приоритет | высокий |
| Окружение | боевой сайт mysuperpetproject.ru, дата прогона 2026-10-16 |
| Статус | новый |
| Связанные кейсы | CANCEL-02, CANCEL-08, CANCEL-03 (заблокирован) |

Возможная причина (гипотеза по коду, не вывод): обработчик смены статуса в админке `admin/order_status.php` только обновляет статус заказа и не возвращает остаток по позициям заказа. Для правки нужно: при первом переходе в «отменён» вернуть остаток каждой позиции (с учётом размера, если он есть), а при повторной отмене не менять остаток (CANCEL-03).
