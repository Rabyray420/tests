# Тест-кейсы магазина Aloha Threads

Ручные тест-кейсы для интернет-магазина Aloha Threads (https://mysuperpetproject.ru/). Кейсы сгруппированы по зонам: корзина, оформление заказа, вход, отмена заказа. Документ в работе: часть зон ещё не заполнена, кейсы пока не прогонялись, поэтому статус выполнения не указан. Общий план тестирования: [test-plan_demo.docx](../test-plan_demo.docx).

Шаблон кейса: ID, название, предусловия, шаги, ожидаемый результат, приоритет. Все данные в кейсах тестовые.
