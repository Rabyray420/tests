# Тесты магазина Aloha Threads

Учебный проект по тестированию интернет-магазина Aloha Threads (https://mysuperpetproject.ru/). Здесь собраны тестовая документация и, в дальнейшем, автотесты. Магазин работает на боевом хостинге, оплата в демо-режиме.

## Что где лежит

| Путь | Содержимое | Статус |
|---|---|---|
| [test-plan_demo.docx](test-plan_demo.docx) | Мини-тест-план: объём, виды тестирования, риски, критерии | Черновик |
| [manual/test-cases.md](manual/test-cases.md) | Ручные тест-кейсы по зонам | В работе |
| [manual/bug-reports.md](manual/bug-reports.md) | Баг-репорты | Первый черновик |
| `api/`, `ui/`, `java/`, `js/` | Автотесты (пока пусто) | Запланировано |

## План ближайших шагов
1. Дописать кейсы по зонам: оформление заказа, вход, отмена заказа.
2. Прогнать кейсы вручную и оформить найденные дефекты.
3. Проверить API магазина и добавить первые автотесты.
