# Aloha Threads: интернет-магазин и QA-проект

Учебный проект: небольшой интернет-магазин гавайских рубашек на PHP и MySQL и тестовая документация к нему. Цель проекта: практика ручного тестирования (тест-план, тест-кейсы, баг-репорты), затем проверка API и автотесты. Работающий экземпляр магазина: https://mysuperpetproject.ru/ (оплата в демо-режиме, реальные платежи не принимаются).

## Что в репозитории

| Путь | Содержимое |
|---|---|
| `hawaii_shirts_v2/` | Код магазина: каталог, корзина, оформление заказа, регистрация и вход, админка |
| `docker-compose.yml`, `docker/` | Локальный стенд: PHP 8.3 + Apache и MySQL 8 |
| `tests/` | Тестовая документация и (в дальнейшем) автотесты, см. [tests/README.md](tests/README.md) |

## Запуск локально (Docker)

1. Скопируйте настройки: `cp hawaii_shirts_v2/config.example.php hawaii_shirts_v2/config.php` (значения для базы подставит docker-compose).
2. Запустите: `docker compose up -d --build`. Сайт откроется на http://localhost:8080.
3. Создайте администратора и демо-товары: `docker compose exec -e ADMIN_PASSWORD=<ваш_пароль> web php seed.php`. Если пароль не задать, скрипт создаст случайный и покажет его один раз.

## Установка на хостинг

1. Создайте базу MySQL и импортируйте `hawaii_shirts_v2/db.sql`.
2. Скопируйте `config.example.php` в `config.php` и впишите данные базы из панели хостинга.
3. Один раз запустите `seed.php`, затем удалите его с сервера.

## Безопасность

В репозиторий не попадают `config.php` (данные базы) и загруженные файлы. Пароли и ключи в коде не хранятся. Доступ к `config.php`, `db.sql` и `includes/` закрыт правилами `.htaccess`.
